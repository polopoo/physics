# 2D-срезы УЗИ → 3D-модель в STL

Из 33 двумерных срезов эмбрионального УЗИ-атласа собирается объём, из него выделяется поверхность и сохраняется STL.

![Основной результат](outputs/result.png)

## Что посмотреть

- `outputs/embryonic_brain_envelope.stl` — простая внешняя оболочка;
- `outputs/details/brain_intensity_surface.stl` — модель с сохранёнными внутренними границами;
- `outputs/details/brain_cutaway.stl` — модель с разрезом, на котором эти границы лучше видны;
- `outputs/result.png` и `outputs/details/comparison.png` — готовые картинки;
- `REPORT_RU.md` — короткий отчёт о работе;
- `reconstruct.py` и `refine_details.py` — основной код.

## Как это работает

1. Из УЗИ-атласа берутся 33 параллельных 2D-среза с известными координатами.
2. Промежутки между ними заполняются линейной интерполяцией.
3. Яркая область отделяется автоматическим порогом Оцу.
4. Из объёма строится треугольная поверхность методом Marching Cubes.
5. Поверхность сохраняется в STL и проверяется на замкнутость.

Основной результат содержит 40 308 треугольников. Файл корректно открывается как STL и состоит из одной замкнутой поверхности.

## Важное ограничение

Это демонстрация метода, а не восстановление внешности конкретного ребёнка. Срезы получены из уже подготовленного усреднённого 3D УЗИ-атласа, поэтому их положение заранее известно. Модель показывает приближённую область головы/мозга, но не лицо, кожу или точную медицинскую анатомию.

Физический масштаб в исходном файле не указан. Размеры STL даны в единицах решётки атласа, а не в миллиметрах.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python reconstruct.py
python refine_details.py
python make_figures.py
```

Повторить реконструкцию только по сохранённым 2D-срезам, не читая полный атлас:

```bash
python reconstruct.py --input data/slices_step4 --output outputs/replay_check
```

Если `data/atlas_56.nii.gz` уже есть, интернет для запуска не нужен.

## Данные

Использован [The 4D Human Embryonic Brain Atlas](https://doi.org/10.5281/zenodo.10549081), созданный на основе 3D УЗИ первого триместра. Лицензия данных — CC BY-NC 4.0.

Для собственных данных нужны параллельные 2D-массивы одинакового размера и координата каждого среза. Произвольно снятое УЗИ-видео без информации о движении датчика этот код не поддерживает.
